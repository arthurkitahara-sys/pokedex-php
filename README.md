# Pokédex PHP

A web-based Pokédex application built with **PHP**, focusing on clean code organization, object-oriented programming, and database integration.

## 🚀 Technologies

* PHP
* HTML5
* CSS3
* SQL
* Object-Oriented Programming (OOP)
* Layered Architecture (Controller / Model / DAO)

## 💡 Features

* Create, update, and delete Pokémon
* Search Pokémon by name
* View detailed Pokémon information
* Store and retrieve data from a database
* Web interface for managing Pokémon records

## 🏗️ Architecture

The project separates responsibilities across different layers:

* **Model** — represents application data and entities
* **DAO** — handles database access and data persistence
* **Controller** — manages application flow and communication between layers
* **Actions** — processes operations triggered by the web interface

This structure demonstrates practical knowledge of **OOP, CRUD operations, database integration, and separation of concerns**.

## 📁 Project Structure

```text
pokedex-php/

├── dao/

├── index.php
└── style.css
```

This project was built to apply practical concepts of **PHP web development, object-oriented programming, database integration, and layered application architecture**.
